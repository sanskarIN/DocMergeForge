# Development Phases and Version Plan

The master prompt is intentionally larger than a safe single implementation step. Work is divided into independently testable versions so incomplete features are never presented as finished.

## v0.1.x — Safe core foundation
- Typed domain model and merge state machine.
- Natural discovery, classification, hashing, missing/duplicate detection.
- Atomic PDF/DOCX merge engines.
- OOXML validation and source-integrity verification.
- SQL Full Mastery 120-part preset.
- Companion-code index only; no code merging.
- Reports, checksums, manifest, publishing checklist.
- CLI, initial desktop shell, branding, CI, unit/integration/regression tests.

## v0.2.x — Project workflow and ordering
- Full graphical file order editor with drag/drop and undo/redo.
- Reusable project files and recovery UI.
- Filename templates.
- Dry-run evidence and storage planning.
- Output comparison screens and boundary preview.

## v0.3.x — Publication tooling
- Front matter generator.
- Visible PDF TOC and page-number/header/footer overlays.
- DOCX heading/section/style inventory.
- Repeated-front-matter detection and publication audit UI.
- Advanced merge profiles.

## v0.4.x — Fidelity adapters
- Interactive encrypted-PDF password-in-memory flow.
- LibreOffice integration.
- Optional Microsoft Word high-fidelity adapter on Windows.
- Risky Word construct review and user choice before merge.

## v0.5.x — Desktop completeness and accessibility
- Full Settings, Help, Recent Projects, Validate, Audit, Compare, and Resume screens.
- Keyboard-first reorder workflow, screen-reader labels, scaling, reduced motion, high contrast.
- Light/dark/system themes and localization-ready strings.

## v0.6.x+ — Packaging and hardening
- Windows installer/portable package, macOS bundle, Linux portable/AppImage pipeline.
- Disk-full, cancellation, crash-recovery, multi-gigabyte and accessibility stress testing.
- Dependency notices and release checksum automation.

## v1.0.0 quality gate
No stable release until all acceptance checks in the master specification are verified. Signed binaries must never be claimed unless actual signing and signature verification are completed.
