# Contributing

Thank you for improving DocMergeForge.

1. Fork and create a focused branch.
2. Use Python 3.12+.
3. Install `pip install -e ".[dev]"`.
4. Run Ruff, Black, mypy, and pytest.
5. Add tests for changed behavior.
6. Preserve the non-destructive source policy.
7. Never add code that merges companion projects.
8. Update documentation and `what_changed.md` for meaningful behavior changes.
9. Use clear conventional commit messages.

Repository-local commit identity may be configured with:

```bash
git config user.email "sanskarin@outlook.in"
```

Do not change another contributor's global Git configuration.
