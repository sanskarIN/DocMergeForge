# Security Policy

## Supported versions

Security fixes are applied to the latest maintained release line. Until `1.0.0`, the project is pre-stable and users should review release notes before upgrading.

## Reporting a vulnerability

Do not post sensitive manuscripts, passwords, or private diagnostics in public issues.

For a private security report, contact:

- Support: `supportramsandesh@gmail.com`
- Business: `sanskarin@outlook.in`

Include the DocMergeForge version, OS, minimal reproduction steps, and a privacy-safe diagnostics export when useful. Never attach confidential manuscript content unless you have explicitly decided it is safe to share.
